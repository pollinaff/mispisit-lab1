# Электронная система записи к врачу

Лабораторная работа №5 (МиСПИСИТ): уведомление о событии после создания записи.

## Что нового в версии 0.0.5

- После успешного создания записи на приём в базу пишется **новая сущность** `system_events`.
- Добавлен экран **«Уведомления»** (`/notifications`): видно, что произошло и какая запись это вызвала.
- До создания записи список уведомлений **пустой**; сообщение появляется только после действия.
- Выбран вариант **уведомление человеку** (внутреннее сообщение в приложении). Экран наблюдения с метриками в эту версию не входит.

## Стек

- Язык: Node.js 20
- Фреймворк: Express 4.21.2
- Шаблонизатор: EJS 3.1.10
- Оформление: Bootstrap 5.3.3 (файлы в образе)
- Драйвер БД: pg 8.13.1
- Хранение: PostgreSQL 16 (отдельный контейнер `db`)

## Запуск

Репозиторий: https://github.com/pollinaff/mispisit-lab1

```text

cd mispisit-lab1
docker compose up -d
```

После запуска откройте в браузере: http://localhost:8080

Проверка уведомления: создайте запись на `/appointments/new`, затем откройте `/notifications`.

### Адреса страниц

| Адрес | Назначение |
|---|---|
| `/` | Главная (версия 0.0.5) |
| `/appointments` | Список записей (из PostgreSQL) |
| `/appointments/new` | Форма создания записи |
| `/appointments/1` | Карточка записи |
| `/appointments/1?as=guest` | Отказ по роли |
| `/access-denied` | Страница отказа |
| `/notifications` | Уведомления о событиях |
